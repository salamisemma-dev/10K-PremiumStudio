# Purpose

- Own reviewed website lessons and reusable pattern records extracted from completed builds.

## Ownership

- `patterns.md` records durable, reviewed lessons that can inform future sites.
- Learning records propose changes to owner files; they do not override the constitution, brand, blueprints, prompts, templates, skills, projects, apps, or checks.

## Local Contracts

- Every adopted pattern must name evidence, what to reuse, what to avoid, pros, cons, and a fix for each con.
- Do not store client secrets, private intake data, or heavy media here.
- Reference external inspiration as influence only; never clone a competitor or reference site.

## Work Guidance

- Promote a lesson here only after it is captured in `projects/<client>/learning.md` and reviewed.
- When a lesson changes rules or workflow, update the owning source file in the same PR.

## Verification

- `npm run test:learning`
- `npm run check:learning`

## Child DOX Index

- `patterns.md` - Reviewed reusable lessons and pattern records.
