# Purpose

- Own reference-learning dossiers for studied external sites, campaigns, brands,
  portfolios, products, and interaction patterns.

## Ownership

- Each child folder is a reference study, not a client project and not a delivered
  website.
- A reference study may use `brief.md`, `content.md`, `assets.md`, `acceptance.md`,
  and `learning.md` so lessons remain comparable with delivered-site learning.
- The study must label itself as reference-only in its evidence or acceptance text.

## Local Contracts

- References are candidates only; the client scene, `brand/manifest.md`, and
  `blueprints/` decide what can be used.
- Never copy protected brand codes, campaign identities, exact layouts, proprietary
  art direction, or distinctive copy from a reference.
- Every reusable lesson needs pros, cons, and a fix for each con.

## Work Guidance

- Keep reference studies lightweight: markdown, URLs, dimensions, hashes, and license
  notes instead of heavy binary assets.
- Promote durable lessons to owner files only through reviewed edits.
- Add new studied references here, not under `projects/`.

## Verification

- `npm run check:learning`
- `npm run test:learning`
