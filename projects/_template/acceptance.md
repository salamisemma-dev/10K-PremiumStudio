# Acceptance

## Required Checks

- `npm run check` passes.
- Exactly one `h1` per route.
- JSON-LD exists and matches the schema type in `brief.md`.
- Unique title, meta description, canonical URL, and crawlable nav links exist per route.
- Every meaningful image has alt text.
- Media has fixed dimensions.
- Reduced-motion fallback exists.
- No em dash characters in website copy.
- Headlines and captions stay within the word limits.
