# Prompt Blueprint: Premium Copywriting

## Goal

Create quiet, factual copy for premium landing pages.

## Rules

- Headlines use three to five words.
- Captions use three to five words.
- Do not repeat headlines.
- Do not use em dash characters.
- Avoid vague promises.
- Use specific proof where available.

## Output Sections

1. Hero messaging.
2. Thesis and proof.
3. Feature details.
4. CTA line.
