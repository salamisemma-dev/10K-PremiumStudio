# Purpose

- Own the Hero Front Expert method for creating elegant, prestigious first-viewport image prompts and hero-front decisions.

## Ownership

- `hero-front-expert.md` owns the method, reference lessons, prompt ingredients, and output quality bar.
- `references.md` records studied inspiration patterns as adopt/leave notes. It is not a clone library.
- Prompt wording that agents reuse lives in `prompts/04-hero-front-prompt.md`.
- Executable prompt generation lives in `checks/hero-front-prompt.mjs`.

## Local Contracts

- Hero front output must derive from the client `scene`, `one thing`, proof, and asset plan.
- Reference sites inform camera, composition, lighting, and restraint only; never copy brand, layout, copy, or exact imagery.
- Every generated prompt must include camera/view, subject, background, lighting, composition, material/texture, negative constraints, aspect ratio, and accessibility notes.
- Keep the prompt useful for Nano Banana Pro, ChatGPT image generation, or another image model without naming a required vendor.

## Work Guidance

- Update this folder before changing hero-front generation behavior elsewhere.
- Prefer one strong hero image direction over multiple vague options.
- Record pros, cons, and a fix for each con when adding reference lessons.

## Verification

- `npm run test:hero`
- `npm run check:hero`
