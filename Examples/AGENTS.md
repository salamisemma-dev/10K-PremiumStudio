# Purpose

- Own archived sources and example materials.

## Ownership

- `_source/` stores original source documents after normalization.
- Example CSV files are reference material, not active project data.

## Local Contracts

- Do not build production sites directly from examples.
- Normalize useful examples into prompts, templates, or project files before implementation.
- Worked walkthroughs (e.g. discovery -> template -> six-field mapping) are illustrative and
  fictional; real client work lives in `projects/<client>/`. A walkthrough must show the
  scene driving the choice and stay offline-first (no stock URLs).

## Work Guidance

- Keep archived source files read-only unless replacing them with a newer source.

## Verification

- `npm run check:structure`
